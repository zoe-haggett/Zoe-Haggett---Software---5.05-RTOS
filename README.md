# Zoe-Haggett---Software---5.05-RTOS
RTOS Project for PAST Software Onboarding


# RTOS Project Deliverables
1. Explain what a queue, mutex and semaphore are in the context of an operating system.
o	Describe a suitable use case for each.
2. Re-create the LED blink program from 5.3 but use two separate tasks to switch the LED on and off at different rates.
3. Create a program that can safely transfer data between two tasks.
o	Some examples of data that could be transferred: Current iteration number, the number of blinks to do, the speed of blinks.
4. Provide an Inter-Process Communication (IPC) Diagram or Task Synchronization Flowchart. 
o	This should outline how the processes interact, share resources, and avoid race conditions.


# Extra Project Deliverables
1. Research how an RTOS could be used in a Flight Computer.
Research could include:
o	Which tasks the system would be responsible for, e.g. polling subsystems, creating packets, sending packets, responding to commands.
o	Which tasks require the highest priority.
o	How the system would handle task failures.
